# Rahul's Poker Toolkit

Personal poker range reference guides and AI trainer.

## Live site
Once deployed: `https://YOUR-USERNAME.github.io/poker-toolkit`

## Contents
- `index.html` — Home page / navigation hub
- `9max-vanilla.html` — 9-Max Vanilla MTT ranges
- `6max-hyper.html` — 6-Max Hyper MTT ranges
- `8max-pko.html` — 8-Max PKO ranges + bounty calculator
- `6max-hyper-pko.html` — 6-Max Hyper PKO ranges
- `sd-pko.html` — 6-Max Short Deck PKO (Triton rules)
- `trainer.html` — AI Poker Trainer (requires internet for API calls)

## Deploy to GitHub Pages

1. Create a new GitHub repository called `poker-toolkit`
2. Upload all files from this folder to the repo
3. Go to repo **Settings → Pages**
4. Under **Source** select **Deploy from a branch**
5. Select branch `main`, folder `/ (root)`
6. Click Save — your site will be live in ~60 seconds

## Add to Android home screen (Chrome)
1. Open `https://YOUR-USERNAME.github.io/poker-toolkit` in Chrome
2. Tap the three-dot menu (⋮)
3. Tap **Add to Home screen**
4. Name it "Poker Toolkit" and confirm

The icon will appear on your home screen and open like an app — full screen, no browser chrome.
